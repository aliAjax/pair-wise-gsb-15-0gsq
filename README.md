# FlowDesk Studio

FlowDesk Studio 是一个完全运行在浏览器中的企业级低代码流程编排与审批监控演示平台。项目使用 React、TypeScript、Vite、Zustand 和 React Flow，所有数据均为本地 mock，不需要后端、登录或外部 API。

## 启动

需要 Node.js 20+。

```bash
npm install
npm run dev
```

打开终端显示的本地地址（默认 `http://localhost:5173`）。建议使用 1440px 或更宽的现代桌面浏览器。

## 测试

首次运行先安装 Chromium：

```bash
npx playwright install chromium
npm test
```

Playwright 会自动启动 Vite（端口 4173），串行验证 Dashboard、编辑器审批配置、双区域校验、条件修复、动态表单预览、发布联动、异常实例详情、版本比较和历史恢复，以及审批委托台的时段重叠拦截、循环委托链拦截、首尾相接登记、表单预览实际代办人解析和“先代办签字再撤销委托、历史签字保留”的完整链路。测试失败时会保留截图和 trace。

## 浏览器验证路径

1. Dashboard 点击“差旅费用审批”进入编辑器。
2. 选择“直属主管审批”，切换审批人来源并保存草稿。
3. 运行校验，观察 Condition 节点红色错误态和底部问题面板。
4. 选择“金额判断”，配置申请金额大于 5000，再次校验。
5. 打开预览，输入金额 12000，观察模拟分支切换。
6. 返回并发布；在 Dashboard 和 Workflows 检查状态及版本。
7. 进入运行监控，筛选异常并打开实例，查看时间线及高亮节点。
8. 从编辑器进入版本历史，选择两个版本比较，再恢复旧版本为草稿。
9. 打开“审批委托台”，查看当前生效委托链；用陈默登记一段与 09-15~09-27 重叠的财务委托，观察冲突报告（委托人、受托人、时段、命中规则）。
10. 把开始时间改为 2026-09-27 18:00（首尾相接）后成功登记并撤销。
11. 以赵安→陈默登记覆盖 09-22 的财务委托，观察循环链拦截与链路 赵安→陈默→王宁→赵安。
12. 在差旅费用审批预览中切换申请人为林秋，确认名义审批人陈默、实际代办人赵安。
13. 在运行监控打开 INS-2026-0001，由赵安代为审批通过，再到委托台撤销陈默→王宁；刷新后委托关系为已撤销，而时间线签字仍保留赵安（代陈默）。

## 委托规则

- 委托按“员工 + 业务域 + 半开时段”登记，同一委托人在同一业务域的时段不得与本人仍生效（未撤销、未结束）的委托重叠；首尾相接（`[a,b)` 与 `[b,c)`）允许登记。
- 系统沿“受托人 → 受托人的受托人”追踪同域、时段有交集的委托，只要存在共同生效时点且链路最终指回委托人本人，即判定为循环委托链并拦截，冲突报告会画出完整链路。
- 实际代办人沿生效委托链解析（支持多跳转委托），表单预览与异常实例详情显示名义审批人、委托链与实际代办人。
- 撤销只影响后续流转；已经产生的人工审批签字固化在实例时间线上（并持久化到 localStorage），撤销或到期都不回改处理人。
- 委托数据与签字记录持久化在浏览器 localStorage，刷新页面后委托关系与流程运行记录保持一致；委托台右上角“恢复演示数据”可一键还原种子数据。

## 项目结构

- `mock-data/`：12 个流程、80 个实例、8 个用户、6 个角色、5 个业务域、直属主管关系、委托种子数据及边界案例。
- `src/components/`：布局、公共状态组件和 React Flow 画布。
- `src/pages/`：Dashboard、流程列表、编辑器、表单预览、运行监控、版本历史、审批委托台。
- `src/store/`：Zustand 全局状态、校验、发布、复制、归档及恢复逻辑；`delegation.ts` 提供时段重叠、循环链与实际代办人解析。
- `src/types/`：核心业务数据 TypeScript 类型。
- `tests/`：关键产品链路 Playwright 测试。

## Mock 边界案例

数据集中包含空流程、孤立审批节点、缺少结束节点、未配置条件分支、审批人为空、表单必填校验、超长流程名称、超长说明展示能力、无异常实例，以及由搜索筛选产生的空结果状态。委托部分包含生效中、待生效、已结束、已撤销四种状态、两跳转委托链、历史代办签字记录，以及时段重叠与循环委托两类冲突场景。
